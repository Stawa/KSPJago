## KSPJago

> [!WARNING]
> Even if you download and install this application, you cannot use it without a valid account. Access is restricted and requires login credentials provided by the system administrator.

## Download

> [!TIP]
> Download the latest version here:
> https://github.com/Stawa/KSPJago/releases

## Installation (Step-by-step)

1. Open the download link above
2. Select the latest release
3. Download:
   * `KSP Jago_x.x.x_x64-setup.exe`
4. Open the downloaded file
5. If Windows SmartScreen appears:
   * Click **More info**
   * Click **Run anyway**
6. Follow the installation steps
7. Open the app after installation
